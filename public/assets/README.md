# Inbox Website Assets

Place future screenshots, school marks, press images, and campaign assets in this
folder. Prefer descriptive, lowercase file names and optimized WebP/AVIF images.

The website currently uses:

- `app-icon.png` for navigation, footer, metadata, and calls to action
- `app-icon-violet.png`, `app-icon-blue.png`, and `app-icon-green.png` as ready
  alternatives for future campaigns
- `og.png` at the `public` root for social previews
